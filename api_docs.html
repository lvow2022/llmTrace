API Documentation

POST /api/trace

Tracing endpoint to record a step in a session.

Request Body


{
    "trace_id": "session_abc123",
    "turn_number": 1,
    "request": {
        "model": "gpt-4",
        "messages": [
            {
                "role": "user",
                "content": "Hello, world!"
            }
        ]
    },
    "response": {
        "id": "chatcmpl-123",
        "object": "chat.completion",
        "created": 1677652288,
        "model": "gpt-4-0613",
        "choices": [
            {
                "index": 0,
                "message": {
                    "role": "assistant",
                    "content": "Hello! How can I assist you today?"
                },
                "finish_reason": "stop"
            }
        ]
    },
    "status": "success",
    "error_message": "",
    "metadata": {
        "user_id": "user_456",
        "tags": ["test", "example"]
    }
}

Responses

200 OK


{
    "success": true,
    "message": "Trace data saved successfully",
    "data": null
}

POST /api/playground/:id/sessions/:session_id/debug

Execute a debug request within a debug session. This will call an external LLM API and record the result.

Path Parameters

NameInTypeDescription
idpathintegerThe ID of the playground.
session_idpathintegerThe ID of the debug session.

Request Body


{
    "turn_number": 2,
    "context": [
        { "role": "user", "content": "Hello!" },
        { "role": "assistant", "content": "Hi there!" }
    ],
    "user_input": "How are you?",
    "provider": "openai",
    "model": "gpt-4",
    "config": {
        "temperature": 0.8,
        "max_tokens": 150
    }
}

Responses

200 OK


{
    "success": true,
    "message": "Success",
    "data": {
        "id": "chatcmpl-456",
        "model": "gpt-4-0613",
        "choices": [
            {
                "index": 0,
                "message": {
                    "role": "assistant",
                    "content": "I'm just a computer program, but I'm doing great! How can I help you?"
                },
                "finish_reason": "stop"
            }
        ],
        "usage": {
            "prompt_tokens": 20,
            "completion_tokens": 15,
            "total_tokens": 35
        }
    }
}
